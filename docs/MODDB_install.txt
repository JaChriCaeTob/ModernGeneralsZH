Zero Hour x64 + Vulkan renderer (experimental): the game as a 64-bit program with a native Vulkan renderer and optional effects (unlocked FPS, soft shadows, new water, shockwaves). Gameplay is untouched. Made by Claude Code; not actively developed, feel free to fork it.

HOW TO INSTALL
1. You need your own Zero Hour 1.04 and a Vulkan 1.3 GPU.
2. Download release.zip: github.com/JaChriCaeTob/ModernGeneralsZH/releases
3. Unzip everything into your Zero Hour folder (the one with the .big files, e.g. INIZH.big).
4. Start Play-Updated.bat for the new graphics, or Play-Original.bat for the old rendering. Never start x64\generalszh64.exe directly.
5. Optional: Install-OptionsMenu.bat (needs Python 3) adds the graphics check boxes to the options menu.

Starts windowed; remove -win in the .bat for fullscreen. Uninstall: delete the x64 folder and the .bat files.

Known bugs: some audio clips play weirdly; dynamic shadows draw above some effects. Multiplayer untested.
